Server Core
⚙️ Timezone Compensation Engine
Device hardcodes UTC+8. Server shifts Date header backwards:
Date: (UTC - Shift) + 8h = Local Time
🤝 Registration & Handshake
GET /iclock/cdata Dispatches sync parameters: Stamp=0, Delay=10, Realtime=1.
💓 Heartbeat & Command Dispatch
GET /iclock/getrequest Monitors terminal connectivity every 10s and dispatches queued tasks.
🛡️ Retransmission Loop Shield
POST /iclock/cdata parses tab-separated punches. Server MUST respond with:
OK: <count> (e.g. OK: 4) — prevents terminal resend loops!

Protocol Request & Response Lifecycle Stateless HTTP • Low Latency • Zero Inbound Firewall Rules
Step 1
Device Boot
Terminal calls GET /iclock/cdata?SN=... Server returns Stamp=0 & Delay=10.
Step 2
Time Sync
Heartbeat GET /iclock/getrequest. Server shifts Date header to counteract UTC+8 bug.
Step 3
Biometric Punch
User clocks in. Device instantly POSTs tab-separated ATTLOG payload to server.
Step 4
Exact Ack
Server inserts records, deduplicates, and responds with mandatory "OK: <count>".
Step 5
ERP Pipeline
Background worker forwards punched batch via Webhook to Payroll microservice.
